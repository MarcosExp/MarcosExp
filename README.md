### 📌 Featured projects

**[micrograd-clone](https://github.com/MarcosExp/micrograd-clone)** · *complete*
Reverse-mode automatic differentiation rebuilt in plain Python — computation graph, topological
backward pass, and a small neural net on top. Gradients verified against PyTorch, plus a few
features the original doesn't have. Written to be read: the math is documented alongside the code.

**[demanda-electrica-model](https://github.com/MarcosExp/demanda-electrica-model)** · *in progress*
Day-ahead forecasting of Spain's hourly electricity demand — predict all 24 hours of day D+1 using
only what's known by 12:00 on day D. Real ingestion, EDA, feature construction and training, built
towards honest evaluation against a seasonal naive baseline, automated retraining and API serving.
